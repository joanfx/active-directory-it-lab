# Active Directory & IT Administration Lab

A hands-on Windows enterprise lab built with Windows Server 2022 and Windows 11 in VMware Workstation.

## Skills Demonstrated

- Active Directory Domain Services
- DNS configuration
- Organizational Units and security groups
- Domain workstation management
- Group Policy
- SMB and NTFS permissions
- Role-based access control
- Account lockout troubleshooting

## Environment

- **Domain Controller:** Windows Server 2022 (`DC01`)
- **Client:** Windows 11 (`CLIENT01`)
- **Domain:** `corp.local`
- **Hypervisor:** VMware Workstation

## Lab Overview

![Domain Join](screenshots/05-client01-domain-join.png)

Configured a Windows Server domain environment, joined a Windows 11 workstation to the domain, managed users and security groups, deployed Group Policy, configured department file permissions, and tested account lockout troubleshooting.
